# Разработчик 1 — Django, данные и API

**Зона:** `backend/`, `infra/`, `compose.yaml`. Django 5.2, DRF, PostgreSQL, Celery, Redis.

1. **Основа:** импорт и проверка CSV Beeline, модели наборов данных, запусков, пилотов и кампаний; API сводки и истории. Закрепить контракт с фронтендом и агентом.
2. **Рабочий сценарий:** запуск агента в Celery, сохранение событий и результатов, получение прогресса через API, отмена и CSV-экспорт. Повторный запрос запуска не должен повторять пилоты.
3. **Сдача:** обработка ошибок и таймаутов, доступ к приложению, проверка полного сценария с React и агентом, запуск всех сервисов через Docker Compose.

**Готово:** импорт → запуск → прогресс → результат → CSV работает через API; повторный запуск запроса не расходует бюджет дважды. Ключ OpenAI доступен только серверу.

**Инструкция ИИ:** прочитай `README.md`, `docs/api-contract.md` и это ТЗ. Выполняй этапы по порядку в `codex/dev1-backend`. Работай в своей зоне; общие контракты обновляй вместе с их потребителями. Используй движок из `packages/campaign_engine`, сохраняй реальные результаты, проверяй изменения тестами.
