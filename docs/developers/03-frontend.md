# Разработчик 3 — React и пользовательский сценарий

**Зона:** `frontend/`. React 18.2, TypeScript, Vite.

1. **Основа:** экраны обзора, аудитории, создания и списка планов; типизированный API-клиент. Отображать данные Django и состояния загрузки, пустого результата и ошибки.
2. **Рабочий сценарий:** кнопка запуска, прогресс и журнал пилотов, остаток бюджета и контактов, таблица выбранных кампаний с объяснениями, CSV-скачивание. Обновлять прогресс опросом API каждые 2 секунды до конечного статуса.
3. **Сдача:** пройти полный сценарий на реальном API, проверить повторный клик, сбой сети и отсутствие данных; адаптировать интерфейс под телефон, проверить сборку и подготовить демонстрацию.

**Готово:** аналитик создаёт план, запускает расчёт, понимает результат и скачивает CSV. Прогнозный эффект и результат симулятора подписаны отдельно; выдуманных показателей нет.

**Инструкция ИИ:** прочитай `README.md`, `docs/api-contract.md` и это ТЗ. Работай по этапам в `codex/dev3-frontend`. Сохрани React 18.2. Данные получай через `src/api/client.ts`; не подключай OpenAI из браузера. Координируй новые поля API с разработчиком 1. Проверяй `npm run build` и пользовательский сценарий в браузере.
