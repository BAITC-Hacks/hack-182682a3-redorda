# Общий контракт

Все сервисы находятся в одном репозитории. React → `/api/v1/` → Django → Celery → `campaign_engine` → публичная среда Beeline / OpenAI Responses API.

## Уже работает в скелете

| Метод | Путь | Результат |
| --- | --- | --- |
| GET | `health/` | Доступность API и БД |
| GET | `meta/` | Лимиты, стоимость каналов, доступные функции |
| GET | `datasets/current/` | Импортированная сводка; 404, если её нет |
| GET / POST | `runs/` | Список планов / создание черновика |
| GET | `runs/{id}/` | Сохранённый план |

POST `runs/`: `name`, `budget` (decimal-строка), `max_contacts`, `max_pilots`, `seed`, `strategy="baseline"`. Набор данных выбирается сервером; без него — 409.

Списки: `{count, next, previous, results}`. Ошибки: `{error: {code, message, fields}}`. ID — UUID; время — ISO 8601; деньги в API — decimal-строки. OpenAPI: `/api/schema/`, просмотр: `/api/docs/`.

## Совместно добавить на этапе 2

- `POST runs/{id}/start/` с `Idempotency-Key`: один запуск Celery, ответ 202.
- `POST runs/{id}/cancel/`: запрос остановки, без повторения уже выполненных пилотов.
- `GET runs/{id}/events/`: журнал с возрастающим ID и параметром `after`.
- `GET runs/{id}/results/`: кампании, расходы, прогноз и отдельно результат симуляции.
- `GET runs/{id}/export/`: CSV только завершённого расчёта; иначе 409.
- Статусы: `draft → queued → running → completed / failed / cancelled`.

Разработчик 1 фиксирует схемы этих ответов до подключения этапа 2. Разработчик 2 предоставляет чистую функцию запуска с наблюдателем событий и сигналом отмены; разработчик 1 сохраняет результаты и управляет задачей; разработчик 3 отображает API. Бизнес-ограничения общие в `packages/campaign_engine/contracts.py`. Проверка лимитов обязательна перед каждым пилотом и финальной кампанией.

## Три общих этапа

1. **Основа:** все согласовали поля, подняли свои части, работает импорт и базовый агент отдельно.
2. **Интеграция:** один реальный запуск проходит из браузера до сохранённого результата.
3. **Сдача:** полный прогон, проверка лимитов и сбоев, воспроизводимый CSV, демонстрация.
