# Сохранённые результаты и CSV

`get_results(run_id)` читает завершённый `CampaignRun`, связанные `CampaignResult`, `RunResult` и `Pilot`. Для остальных статусов он выбрасывает `ResultNotReady`; завершённый запуск без сохранённой сводки или с недопустимыми кампаниями выбрасывает `InvalidSavedResult`. Вызов не запускает агента, LLM или пилоты.

Ответ содержит `run_id`, `status`, `campaigns`, `totals`, `warnings`. Кампании упорядочены по `rank`; `parameters` содержит фильтры аудитории, целевой тариф и канал по публичному контракту. `metrics.cost` и `metrics.n_contacts` присутствуют всегда: известные значения передаются как decimal-строка и целое число, отсутствующие — `null`. Другие показатели движка сохраняются без подстановки. `explanation` — текст движка либо `null`, если он его не предоставил; в этом случае добавляется предупреждение.

`totals.pilot_cost` суммирует фактическую стоимость сохранённых пилотов. `totals.campaign_cost` суммирует `metrics.cost` лишь когда стоимость известна для каждой кампании. `totals.total_cost` включает пилоты и равен `null`, когда стоимость хотя бы одной кампании неизвестна. Аналогично `total_contacts` включает контакты пилотов, когда известны `metrics.n_contacts` всех кампаний. Денежные суммы передаются decimal-строками с двумя знаками. Проверяются бюджет запуска, лимиты контактов, пилотов, 1–10 кампаний, число контактов каждой кампании и допустимые значения полей кампании.

`totals.predicted_effect` читается только из `RunResult.summary.predicted_effect`, `totals.simulator_result` — только из `RunResult.summary.simulator_result`. Если значение не сохранено, оно равно `null` и добавляется предупреждение. Сервис не суммирует прогнозы отдельных кампаний: аудитории могут пересекаться. Записывающий процесс должен сохранять общий прогноз лишь после дедупликации клиентов, а результат симулятора — отдельно и с его происхождением. Никакой результат сервиса сам по себе не обозначает официальную конкурсную оценку.

`iter_submission_csv(run_id)` потоково выдаёт строки CSV с разделителем `,`, переносом `\n`, Unicode и стандартным экранированием кавычек. Первая строка — ровно `campaign_name,filter_arpu_segment,filter_data_segment,filter_call_segment,filter_current_tariff,target_tariff,channel`. Далее идут только сохранённые финальные кампании по `rank`; отсутствующие фильтры представлены пустыми ячейками. Список кампаний снимается до первой выдачи строки, поэтому две выгрузки неизменённого сохранённого результата идентичны. Это **экспорт сохранённого результата**, а не подтверждённый официальный `submission.csv`. Для такого подтверждения нужен отдельный запуск публичного `make_submission.py` на том же seed и той же стратегии и сравнение файлов.
