# Работа команды RedOrda

- Стек: Django 5.2, React 18.2; один монорепозиторий.
- ТЗ и инструкции для трёх разработчиков: `docs/developers/`; общий контракт: `docs/api-contract.md`.
- Текущая итерация «Живая AI-команда»: сначала читать `docs/developers/00-team-plan.md` и `docs/team-contract.md`. Последний описывает целевой контракт, а не уже доступные API. Три разработчика работают параллельно в отдельных worktree.
- Backend владеет `backend/` и инфраструктурой; AI — `packages/campaign_engine/` и `agent.py`; frontend — `frontend/`.
- Движок не импортирует Django. Веб и судейский вход используют одну стратегию.
- Не коммитить `.env`, ключи, локальную БД, `node_modules`, сгенерированные результаты и пакет данных организаторов.
- Исключение по запросу владельца: четыре исходных CSV в `data/demo/` входят в репозиторий для кнопки демоимпорта. Остальной пакет организаторов и пользовательские загрузки не коммитить.
- Работать с публичным API среды; не менять оценщик и не извлекать скрытые эффекты.
- Не показывать выдуманные результаты. Отсутствующий функционал обозначать явно.
- Перед сдачей выполнить `make check`; при изменении API обновить схему через `make schema` и типы фронтенда.
