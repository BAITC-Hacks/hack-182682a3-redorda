# Пользовательский сценарий кампании

React 18.2: вход → создание черновика → запуск → прогресс и пилоты → кампании → CSV.
Демонстрационных результатов в интерфейсе нет; тестовые ответы находятся только в тестах.
`npm test` проверяет сценарий на границе HTTP, `npm run build` проверяет типы и сборку.
Обе проверки входят в корневой `make check`.

## Контракт

Источник: [API-контракт](../docs/api-contract.md), [OpenAPI](../docs/openapi.yaml).
`src/api/types.ts` описывает wire-формат, `adapters.ts` переводит его в представление UI:

- `Run.progress`: `stage`, `percent`, `spent_budget`, `used_contacts`, `completed_pilots`.
- Журнал: `{results: [{id, kind, payload, created_at}], next_after, has_more}`.
  Курсор эксклюзивный; все страницы дочитываются, в том числе после завершения.
- Результат: `{run_id, status, campaigns: [{rank, parameters, explanation, metrics}], totals, warnings}`.
  Расходы и контакты берутся из `total_cost` и `total_contacts`; прогноз — из
  `predicted_effect`, отдельный результат среды — из `simulator_result`.
  `null` не превращается в нулевой расход или выдуманный эффект.
- `meta.environment.label` обозначает режим. Локальная симуляция не выдаётся за судейство.
  Прирост ARPU пилота (`observed_lift_ratio`) отображается в процентах, не деньгах.
- CSV скачивается с сервера, без пересчёта или самостоятельной генерации submission.

`meta.features.run_execution` управляет доступностью запуска/отмены и журнала;
`csv_export` — скачиванием. Старт передаёт `Idempotency-Key`, сохраняемый в sessionStorage.
Повтор после потери ответа использует тот же ключ. POST автоматически не повторяется.
Отмена подтверждается пользователем; polling продолжается до конечного статуса.

Чтение обновляется каждые 2 секунды без перекрытий. При сетевой ошибке сохраняются
последние данные с предупреждением. После конечного статуса регулярный опрос
останавливается; недоступные результаты/журнал можно запросить повторно.
Уход со страницы прерывает запросы.

Вход использует `auth/me`, `auth/csrf`, `auth/login` и `auth/logout`, cookie-сессию
и `credentials: same-origin`. CSRF-токен берётся из JSON и обновляется после входа;
пароль не сохраняется. `not_authenticated` возвращает экран входа и останавливает
polling. Создать пользователя может администратор через `manage.py createsuperuser`.
